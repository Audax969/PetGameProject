# Картинки питомцев

Добавьте изображения в эти папки в формате SVG или PNG. Для каждого питомца программа сначала ищет SVG, затем PNG:

- `cats/cat_1.svg` (или `.png`), `cats/cat_2.svg` (или `.png`), ... — изображение кота соответствующего уровня;
- `parrots/parrot.svg` (или `.png`) — изображение попугая.

Рекомендуется квадратное изображение с прозрачным фоном. Размер клеток масштабируется автоматически. Если файла пока нет, игра показывает цветной блок с названием и уровнем. После добавления файлов перезапустите игру; программа также ищет картинки в `assets` рядом с исполняемым файлом. Для SVG-сборки требуется модуль Qt SVG.
